## 各里程碑要点

### M1 · LED 点灯（JTAG）
- 纯 PL 设计，用板载 `sys_clk=U18(50MHz)`、`sys_rst_n=N16`，LED `led0=H15/led1=L15`。
- **JTAG 烧录**（Vivado Hardware Manager → Program Device → `led_blink.bit`），最快验证“板子能配置+FPGA能跑”。
- 无需 SD/PS/DDR，第一个必跑分支。

### M2 · SD 启动 + 串口
- 引入 Zynq PS 系统（FSBL 配置 DDR/时钟），SD 启动加载 `BOOT.BIN`（FSBL+位流+应用）。
- 控制台 **UART0 = MIO14/15 @115200**（注意：板子上 P5 跳线要设为 **PS 串口模式**）。
- 验证了 SD 启动、DDR、串口。

### M3 · CPU→AXI→PL 加速器
- PS(ARM) 经 **AXI4-Lite** 往 PL 加速器 `conv_accel_axi_lite` 写 A/B/C/D，触发后读回 `A*B+C*D`。
- `[CHAIN OK] RESULT=87`——**CPU-FPGA-NPU 链路在真机跑通**，这是整个项目的地基。

### M4a · 真 3×3 卷积
- `conv2d_accel`（AXI4-Lite 从机）：PS 写入 4×4 图(0..15) + 3×3 核(全1)，触发计算，读回 2×2 输出。
- 3×3 核在 4×4 图上滑动 → `(4-3+1)=2×2` 输出 = 每个 3×3 窗口求和。
- 实测：`45 54 / 81 90`，与 CPU 参考一致，`[CONV2D OK]`。**这是真正的卷积算子跑通**。

## 下一步 M4b（真 CNN / MNIST）方案要点
1. **网络**：LeNet-5 级（Conv3×3→ReLU→Pool→Conv→FC），MNIST 输入 28×28。
2. **数据搬运**：加 **DMA / AXI-Stream**，把真实图像+权重从 DDR 喂给加速器（现在只吃寄存器小图）。
3. **权重**：PyTorch 训练/下载 MNIST 权重量化(int8)，导出数组文件。
4. **验证**：PS 喂手写数字图→加速器推理→串口打印「识别为 X」。

> 注意：M4b 在 M3/M4a 的链路上盖楼，需处理数据流、多层、量化、DMA。
