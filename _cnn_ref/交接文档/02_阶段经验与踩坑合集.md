# 02 · 阶段经验与踩坑合集（很重要，别再踩）

> 全部来自实际操作，按「现象→原因→解决」记录。**交接前务必读一遍。**

## A. 关键环境坑

| # | 坑 | 现象 | 原因/解决 |
|---|---|---|---|
| 1 | **路径含中文** | HLS 报 `name contains illegal character` | Xilinx 工具在 Windows 上不认中文/非 ASCII 路径。**可构建工程必须放纯 ASCII 路径**（本工程 `D:\FPGA2026_PRJ\zynq_ai_accel`）。中文目录只放文档/归档。 |
| 2 | **open_project 带盘符** | HLS `open_project` 报 `illegal ':'/'` | 先 `cd` 到目标目录，再用**纯工程名** `open_project -reset name`。 |
| 3 | **HLS 少 solution** | `csynth_design` 报 `You must open a solution first` | 加 `open_solution -reset` + `set_part` + `create_clock`。 |
| 4 | **HLS export 参数** | `export_design` 报 `Unknown option '-output'` | 2018.3 无 `-output`；用 `-ipname`/`-vendor`/`-library`。 |
| 5 | **HLS csim / IP 打包** | `can't read "::AESL_CSIM::gLogfl"`；`bad lexical cast ... core_revision` | csim 该 build 已知问题；IP 打包 locale bug。**综合/生成 RTL 正常**，C 仿真改用 xsim 手工验证。 |
| 6 | **write_hw_platform 缺失** | `invalid command name`（WebPACK 授权） | 用 `write_sysdef -hwdef <.hwdef> -bitfile <.bit> -file <.sysdef>`，再复制为 `.hdf`。**xsct `createhw -hwspec <design_1.hwh>` 可直接用 `.hwh`！** |

## B. Block Design / 综合坑

| # | 坑 | 现象 | 解决 |
|---|---|---|---|
| 7 | **自定义模块进 BD** | `design_1_<cell>_0_0 not found` | 无头 TCL 下 `-type module` 不被综合。**先把 RTL 打包成自定义 IP**（`ipx::package_project`），BD 里用 `-type ip -vlnv user.org:user:X:1.0`。 |
| 8 | **headless OOC 综合** | Xilinx IP 也报 `not found` | `synth_design` 直跑不触发 IP OOC。**用 `launch_runs -jobs N synth_1`**（自动触发 IP OOC）再 `wait_on_run`。 |
| 9 | **单从机 AXI 互联** | 自定义 IP 作唯一从机（NUM_MI=1）真机 AXI 写卡死 | **用 NUM_MI=2**（多放一个 AXI GPIO），与已验证跑通的结构一致。 |
| 10 | **位宽截断** | `3'd8`(3位)、`6'h40`(6位) 超出位宽被截断（`3'd8`→0） | **常量位宽要够**：用 `4'd8`、`7'h40`；寄存器映射值确保在地址位宽内。 |

## C. 软件/SDK 坑

| # | 坑 | 现象 | 解决 |
|---|---|---|---|
| 11 | **BSP 无头文件** | 编译报 `xil_io.h: No such file` | 先 `projects -build -name <bsp> -type bsp` 生成全套头文件，再 build app。 |
| 12 | **命令已弃用** | `set_build_config`/`build_project` 报 bad option | 用 `configapp` / `projects -build -name X -type app`。 |
| 13 | **SDK 流程** | — | `setws` → `createhw -hwspec <hwh>` → `createbsp -proc ps7_cortexa9_0 -os standalone` → `createapp -app {Empty Application}` → `importsources` → `projects -build -type app` → FSBL(`{Zynq FSBL}`) → `bootgen` 出 BOOT.BIN。 |

## D. 关键固定参数（拿走即用）

- **器件**：`xc7z020clg400-1`
- **PS 配置（官方）**：DDR3=`MT41K256M16 RE-125`，x32 总线，`DDR3_1066F`，533.33MHz；`PS_CLK 33.333MHz`；`MIO bank0=3.3V / bank1=1.8V`；**UART0=MIO14/15 @115200**；QSPI=MIO1..6（启动），SD0=MIO40..45（启动）。
- **串口**：115200 · 8N1 · 无流控；**板载 P5 跳线设为 PS 串口模式**（否则 PS 打印看不到）。
- **启动**：SD 卡 FAT32，根目录放 `BOOT.BIN`；boot mode=SD。
- **加速器基址**：`0x43C00000`（AXI4-Lite，assign_bd_address 自动分配）。
- **PL 引脚**（XDC）：`sys_clk U18`、`sys_rst_n N16`、`led0 H15`、`led1 L15`、`beep M14`、`key L14/K16`、`USB-UART T19/J15` 等（详见 `NAVIGATOR_ZYNQ_IO.xdc`）。

## E. 工具链版本提醒
- 正点原子官方例程是 **Vitis 2020.2**，竞赛官方推荐 **Vivado/Vitis 2025.2 或 2026.1**。
- 本项目用 **2018.3** 先跑通。升级后：PS 配置的 `PCW_*` 值、XDC、TCL 脚本可复用（重建工程），但 `.xpr`/位流不跨版本。
