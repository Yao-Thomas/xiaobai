# 03 · 板卡配置（正点原子 领航者 ZYNQ 7020 V3.9）

> 依据：正点原子官方资料盘 A 盘（`4_Source_Code\…\system_processing_system7_0_0\ps7_parameters.xml`），权威、可上板。

## 板型确认
- **领航者 ZYNQ 开发板 7010/7020 (V2)**；核心板 **V2.5**；底板 **V3.9**（V3.8 起音频已从 WM8960 换成 **ES8388**）。
- 器件：**XC7Z020-CLG400-1**。

## PS（processing_system7）关键配置
| 项目 | 值 |
|---|---|
| PS_CLK 晶振 | 33.333333 MHz |
| ARM 时钟 | 666.666666 MHz |
| MIO Bank0 | LVCMOS 3.3V |
| MIO Bank1 | LVCMOS 1.8V |
| DDR3 型号 | **MT41K256M16 RE-125**（Micron，4Gb/颗） |
| DDR 位宽 | **32 Bit**（2 颗 x16 并联 ≈ 1GB） |
| DDR speed bin | DDR3_1066F　频率 **533.333 MHz**　CL=7/CWL=6 |
| UART0（控制台） | **MIO 14..15 @115200** |
| QSPI（启动） | MIO 1..6，GRP_SINGLE_SS |
| SD0（启动） | MIO 40..45；CD=MIO10 |
| 需打开（我们链路） | `M_AXI_GP0=1`、`FCLK_CLK0=100MHz` |

## 外设引脚（PL，来自 NAVIGATOR_ZYNQ_IO.xdc）
| 功能 | 引脚 |
|---|---|
| sys_clk（50MHz） | U18 |
| sys_rst_n | N16 |
| led[0]/led[1] | H15 / L15 |
| key[0]/key[1] | L14 / K16 |
| beep | M14 |
| USB-UART（EMIO） | T19(d)/J15(r) |
| IIC scl/sda | E18 / F17 |
| 完整全表 | `3_开发板原理图和硬件相关文件\NAVIGATOR_ZYNQ_IO.xdc` |

## 启动 / 配置操作
- **Boot mode=SD**（启动源选 SD0）。
- **板载 P5 跳线帽 = PS 串口模式**（把 CH340 USB 串口接到 PS UART，否则 PS 打印看不到）。
- **串口**：115200 · 8N1 · 无流控。
- 烧录：`BOOT.BIN` 放 SD 卡根目录（FAT32），上电从 SD 启动。
