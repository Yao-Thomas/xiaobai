# 04 · 构建与复现指南

> 在纯 ASCII 目录 `D:\FPGA2026_PRJ\zynq_ai_accel` 下操作。所有构建脚本都在 `build\`。

## 0. 前置
- 环境：Vivado/SDK/Vitis HLS 2018.3，装于 `D:\Xilinx`。
- license：**必须设置 `XILINXD_LICENSE_FILE=D:\Xilinx\licence\vivado_lic2037.lic`**（已设为用户级环境变量）。
- 每次调用工具前：`$env:XILINXD_LICENSE_FILE="D:\Xilinx\licence\vivado_lic2037.lic"`。

## 1. 各里程碑一键复现脚本（`build\run_*.tcl`，用 `vivado -mode batch -source …`）

### HLS（conv2d 核，C++→RTL）
```
vivado -mode batch -source build\run_hls_synth.tcl    # 生成 RTL（Verilog/VHDL）
```

### LED 点灯（M1，纯 PL）
```
vivado -mode batch -source build\run_led_build.tcl     # => board\led_blink.bit（JTAG 烧）
```

### 自定义 IP 打包（把 RTL 加速器做成 Vivado IP）
```
vivado -mode batch -source build\package_ip.tcl          # conv_accel_axi_lite（M3）
vivado -mode batch -source build\package_ip_conv2d.tcl   # conv2d_accel（M4a）
```
> 打包后 IP 在 `build\ip_repo*\`（component.xml + src + xgui）。

### M3 链路（CPU→AXI→乘加器）
```
vivado -mode batch -source build\run_bd_board.tcl       # 建 BD（官方PS配置+AXI+GPIO+acceler IP）
vivado -mode batch -source build\run_synth_board.tcl    # 综合/实现/bitstream（launch_runs）=> board\chain_board.bit
```
之后生成 hdf 并编 SDK + BOOT.BIN（见 §3）。

### M4a 真卷积（conv2d_accel）
```
vivado -mode batch -source build\run_bd_conv2d.tcl      # BD（NUM_MI=2：AXI GPIO + conv2d_accel，重要）
vivado -mode batch -source build\run_synth_conv2d.tcl   # => board\chain_conv2d.bit
```

## 2. 生成 .hdf（绕过 write_hw_platform）
- 用 `write_sysdef`：`build\generate_hdf_conv2d.tcl`（或对应的），得到 `.sysdef`，再**复制为 `.hdf`**。
- 例：`copy board\chain_conv2d.sysdef board\chain_conv2d.hdf`。

## 3. 编 SDK + BOOT.BIN（用 xsct）
- `build\build_boot_conv2d.tcl`（xsct 脚本）：
  `setws → createhw -hwspec <hwh/hdf> → createbsp → build bsp → createapp(Empty) → importsources(main) → build app → createapp(Zynq FSBL) → build fsbl`
- 然后：
```
bootgen -image board\boot_conv2d.bif -o board\BOOT_CONV2D.BIN -w -arch zynq
```
> `.bif` 内容：`[bootloader] fsbl.elf` + `.bit` + `app.elf`。

## 4. 上板
1. SD 卡格式化 **FAT32**，把 `BOOT_CONV2D.BIN`（或 `BOOT.BIN`）拷到根目录，**改名 `BOOT.BIN`**。
2. Boot mode=SD；**P5 跳线=PS 串口模式**；Type-C 插「USB 串口」口。
3. 串口 **115200 · 8N1 · 无流控**。
4. 上电，看串口：M4a 应输出 `[CONV2D OK]`、`45 54 / 81 90`。

## 5. 常见复现报错 → 查 `02_阶段经验与踩坑合集.md`
- `module not found` → 是否用了 `launch_runs`。
- `AXI 写卡死` → AXI 互联是否 **NUM_MI=2**。
- `xil_io.h` 找不到 → 先 `projects -build -name <bsp> -type bsp`。
- 中文路径报错 → 工程必须放 ASCII 路径。
