# PetaLinux + RGB LCD 系统 —— 总方案与操作手册

> 目标：在**正点原子 领航者 ZYNQ7020** 上跑 **PetaLinux**，用 **7 寸 RGB LCD(1024×600)** 出画面。
> —— 把项目从"裸机加速器"升级为"**带操作系统的平台**"，上限高很多。
> （示波器等应用改到**另一块野火板**上做，本板只做"系统 + 屏幕"。）

---

## 0. 一句话路线

```
Ubuntu16.04 虚拟机(装 PetaLinux2018.3)
   → Vivado 建"显示通路"硬件(PS+VDMA+VTC+RGB LCD)
   → 导出 .hdf
   → PetaLinux 生成 Linux 镜像(BOOT.BIN + image.ub)
   → SD 卡启动，LCD 出画面
```

---

## 1. 三个硬前提（先解决，否则做不动）

| # | 前提 | 说明 |
|---|---|---|
| **P1** | **Linux 主机** | PetaLinux 只能在 Linux 跑。在 Windows 里装 **VMware/VirtualBox + Ubuntu 16.04**（官方配套版本）。给虚拟机 **≥100GB 磁盘、≥8GB 内存**。 |
| **P2** | **PetaLinux 2018.3 安装包** | 与 Vivado 2018.3 版本严格对应。Xilinx 官网下载 `petalinux-v2018.3-final-installer.run`（约 7GB+）。在 Ubuntu 里安装。 |
| **P3** | **正点原子的 Linux 资料** | 下载[《领航者 ZYNQ 之 Linux 开发指南》](http://openedv.com/forum.php/forum.php?mod=page=1&tid=319886)配套资料（含他们已调好的 Vivado 工程 / PetaLinux 配置 / 设备树 / 镜像）。**强烈建议以它为基线**，我们在其上做"系统+屏幕"。 |

> ⚠️ 版本铁律：**Vivado 2018.3 ↔ PetaLinux 2018.3 ↔ Ubuntu 16.04** 三者配套，别混版本。

## 2. 分阶段（每阶段都能单独验证，延续我们"一小步一验证"的做法）

### P0｜Linux 环境（主机侧，你操作）
- 装 VMware/VirtualBox → 装 Ubuntu 16.04 桌面版。
- 装 Vivado 2018.3（Linux 版）+ PetaLinux 2018.3。
- 验证：`petalinux-util --version` 能出版本。

### P1｜先用正点原子的现成镜像把板子跑起来（**关键第一步，先证明能启动**）
- 用正点原子**提供的 PetaLinux 镜像**（BOOT.BIN + image.ub + rootfs）烧 SD 卡。
- 上电，串口看 Linux 启动；LCD 是否点亮/显示。
- ✅ 通过标准：串口进到登录/命令行，LCD 有显示。
- ➜ 这一步**不改任何东西**，纯粹验证"系统能跑、屏能亮"。若这一步不通，先别往下走。

### P2｜Vivado"显示通路"硬件
- 新建 Vivado 工程，PS7（官方板级配置）+ 显示流水线：
  - `AXI VDMA`（DDR 帧缓冲 → AXI4-Stream）
  - `Video Timing Controller (v_tc)`（1024×600 时序）
  - `AXI4-Stream to Video Out`（`v_axi4s_vid_out`）
  - `RGB2LCD`（RGB 并行输出到 LCD 排线）
  - `AXI GPIO`（LCD 背光/使能）
  - AD9280 采集：PL 侧采集 IP（AXI-Stream FIFO / 自研）→ VDMA 写 DDR
- 导出 `.hdf`（我们用已验证的 `write_sysdef` 规避 WebPACK 限制）。
- ✅ 通过标准：时序收敛，导出 .hdf。
- 📄 见 `02_显示通路_Vivado_说明.md` + `run_bd_display.tcl`（起点脚本）。

### P3｜PetaLinux 构建
- `petalinux-create` 建工程 → 用 P2 的 `.hdf` 配置硬件 → `petalinux-config`（根文件系统选 **Qt 或带桌面**）→ `petalinux-build`。
- 产物：`BOOT.BIN`、`image.ub`。
- ✅ 通过标准：SD 启动，LCD 显示控制台；`/dev/fb0` 存在。
- 📄 见 `01_PetaLinux_流程.sh`。

### P4｜framebuffer / GUI 打通
- 确认 framebuffer：`cat /dev/urandom > /dev/fb0` 屏幕花屏（证明能画）。
- 跑一个最小 Qt/LVGL 程序，在 LCD 上显示窗口。
- ✅ 通过标准：LCD 上出现你的 GUI 窗口。

### P5｜应用（**本板不做**）
- 示波器等应用改到**另一块野火板**上做（资料之后给 md）。本板到此为止：系统 + 屏幕。

## 3. 硬件操作（你来做，我这边给文件/命令）

1. **装 Ubuntu 16.04 虚拟机**（VMware 最简单）；给它 ≥100GB/8GB。
2. 在虚拟机里装 **Vivado 2018.3 (Linux)** 与 **PetaLinux 2018.3**。
3. 下载**正点原子领航者 Linux 资料**（镜像 + 工程 + 教程）。
4. 先按 **P1** 用现成镜像烧 SD 卡，确认板子能起 Linux + 屏能亮 → 把串口/屏幕结果发我。
5. 之后按 P2→P4 推进，每步我出脚本/工程，你跑 + 上板验证。

**SD 卡启动方式**（和现在一致）：FAT32 分区放 `BOOT.BIN` + `image.ub`；拨码 SD 启动；串口 115200-8N1。

## 5. 风险 / 提醒

- **最大门槛是 Linux 主机 + PetaLinux 安装**（耗时长、占磁盘）。若能拿到**正点原子现成镜像**先跑通 P1，"能做"这件事就已被证明。
- **显示通路（P2）是本项目最复杂的硬件部分**，务必**以正点原子教程为基线**，别硬造。
- 工具链升级（2025.2/2026.1）时，PetaLinux 版本也要跟着升，流程概念一致。
- 这套做完，你的竞赛故事就从"加速器"升级为"**基于 Zynq 的嵌入式智能仪器平台**"（Linux + GUI + AI 加速），完整度和说服力都强很多。
