# 03 · 7 寸 RGB LCD 1024×600 —— 时序与设备树

> ⚠️ 下面的时序是**常见 1024×600 RGB 面板的参考值**。**必须与你手上正点原子屏的实际参数核对**
> （屏的资料/正点原子工程里有），否则会黑屏/偏移/花屏。

## 1. 参考时序（60Hz，DCLK≈51.2MHz）

| 参数 | 值 | 说明 |
|---|---|---|
| clock-frequency | 51200000 (51.2MHz) | 像素时钟 |
| hactive | 1024 | 水平有效 |
| hfront-porch | 160 | 水平前肩 |
| hback-porch | 140 | 水平后肩 |
| hsync-len | 20 | 水平同步宽 |
| vactive | 600 | 垂直有效 |
| vfront-porch | 12 | 垂直前肩 |
| vback-porch | 20 | 垂直后肩 |
| vsync-len | 3 | 垂直同步宽 |
| 极性 | hsync/vsync 常为负极性 | 按屏资料 |

（水平总 1344 × 垂直总 635 × 60Hz ≈ 51.2MHz，自洽。）

## 2. 设备树片段（display timing + DRM/VDMA）

把显示时序作为子节点挂到显示控制器下（PetaLinux 生成的 DT 里会有 `xlnx,axi-vdma` /
`xlnx,v-tc` / `xlnx,axi4s-vid-out` 等节点，具体名字以生成的 `system.dts` 为准）：

```dts
/ {
    /* 显示时序：1024x600 */
    display_timing: timing_1024x600 {
        clock-frequency = <51200000>;
        hactive = <1024>;
        vactive = <600>;
        hfront-porch = <160>;
        hback-porch  = <140>;
        hsync-len    = <20>;
        vfront-porch = <12>;
        vback-porch  = <20>;
        vsync-len    = <3>;
        hsync-active = <0>;   /* 负极性，按屏改 */
        vsync-active = <0>;
        de-active    = <1>;
        pixelclk-active = <1>;
    };
};

/* VDMA / v_tc / vid_out 由 PetaLinux 自动生成；确保其 timing 指向上面 */
&axi_vdma_0 {
    status = "okay";
};
&v_tc_0 {
    status = "okay";
};
&v_axi4s_vid_out_0 {
    status = "okay";
};
```

framebuffer 相关内核选项（`petalinux-config -c kernel`）：
- 旧方案：`CONFIG_FB_XILINX`（xilinxfb）
- 新方案：`CONFIG_DRM_XLNX` / `CONFIG_DRM_XLNX_DMA`（DRM/KMS）——与 2018.3 的 BSP 版本有关，**以正点原子教程为准**。

## 3. 上板自检命令

```sh
dmesg | grep -i -E 'drm|fb|vdma|v_tc|lcd'
ls -l /dev/fb0            # 存在=fb 驱动 ok
cat /dev/urandom > /dev/fb0   # 屏幕花屏=能画
fbset -i                  # 看分辨率/色深
```

若黑屏：先查①时序参数 ②LCD 引脚约束 ③背光 GPIO ④像素格式(888/565)是否与驱动一致。
