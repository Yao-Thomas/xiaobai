# 05 · 硬件操作清单（你来操作，逐项打勾）

> 每完成一项，把结果/截图发我，我据此准备下一步的文件。

## 阶段 P0：Linux 环境（最花时间，先起）
- [ ] 装 **VMware Workstation**（或 VirtualBox）
- [ ] 建 **Ubuntu 16.04 桌面版** 虚拟机：**磁盘 ≥100GB、内存 ≥8GB、CPU ≥4 核**
- [ ] 在虚拟机里装 **Vivado 2018.3（Linux 版）**
- [ ] 下载 **PetaLinux 2018.3 安装包** 并在 Ubuntu 里安装
- [ ] 验证：终端执行 `petalinux-util --version` 能出版本号
- 📸 发我：Ubuntu 版本、Vivado/PetaLinux 是否装好

## 阶段 P1：先用现成镜像证明板子能跑 Linux（关键）
- [ ] 到 **正点原子资料**下载：[《领航者 ZYNQ 之 Linux 开发指南》](http://openedv.com/forum.php/forum.php?mod=page=1&tid=319886)配套的 **Linux 镜像**（BOOT.BIN、image.ub、rootfs）
- [ ] 准备 **SD 卡（≥8GB，Class10）**，FAT32 分区
- [ ] 按教程把镜像拷到 SD 卡
- [ ] 拨码：**SD 启动**；接 **USB 串口**（115200-8N1）；接 **7 寸 RGB LCD** + 背光电源
- [ ] 上电，串口看 Linux 启动日志；看 LCD 是否点亮
- 📸 发我：串口完整启动日志 + LCD 拍照
- ✅ **通过标准**：串口进到登录/命令行（或桌面），LCD 有显示

## 阶段 P2：Vivado 显示通路
- [ ] 打开正点原子的 **LCD 显示 Vivado 工程**（或按 `run_bd_display.tcl` 起点自建）
- [ ] 确认 PS 配置 = 官方板级配置（DDR3 MT41K256M16/1066F、UART0 MIO14-15、SD0 MIO40-45…）
- [ ] 显示流水线：VDMA + v_tc(1024×600) + v_axi4s_vid_out + GPIO(背光)
- [ ] LCD 引脚约束（XDC）按你屏的排线写（模板 `xdc/lcd_template.xdc`）
- [ ] 综合实现，确认时序收敛
- [ ] 导出 .hdf（用 `write_sysdef` 方法，见 `02_显示通路_Vivado_说明.md`）
- 📸 发我：BD 截图 / 时序报告 / 是否有报错

## 阶段 P3：PetaLinux 构建
- [ ] 按 `01_PetaLinux_流程.sh` 建工程、导入 .hdf、配置、`petalinux-build`
- [ ] `petalinux-package --boot` 生成 BOOT.BIN + image.ub
- [ ] 烧 SD，上电，串口 + LCD
- 📸 发我：构建日志尾部 + 上板结果

## 阶段 P4：framebuffer / GUI
- [ ] 上板执行 `ls -l /dev/fb0`、`cat /dev/urandom > /dev/fb0`（花屏=能画）
- [ ] 跑一个最小 Qt 或 LVGL 窗口到 LCD
- 📸 发我：LCD 上的窗口截图

## 阶段 P5：应用（**本板不做**）
- 示波器改到**另一块野火板**上做（资料你之后给 md）。本板到此为止：系统 + 屏幕。
