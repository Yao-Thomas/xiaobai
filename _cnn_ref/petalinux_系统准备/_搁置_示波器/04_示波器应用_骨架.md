# 04 · 示波器应用骨架 —— P5 阶段

> 目标：在 Linux 里跑一个 GUI 应用，从 AD9280（经 PL 采集 + VDMA）读到采样数据，在 7 寸 LCD 上画实时波形。

---

## 1. 数据从哪来

```
AD9280 ─> PL采集RTL ─AXI4-Stream─> VDMA S2MM ─> DDR ─┬─ /dev/video0 (V4L2)  ← 应用读
                                                     └─ 或 自研字符设备/UIO
```

两种读法：
- **V4L2**：把 VDMA 当 capture 设备，应用用 `VIDIOC_DQBUF` 拿帧。标准但配置略繁。
- **UIO / 自研字符设备**：把 VDMA 或采集 FIFO 的寄存器暴露给用户态（最简，适合自研）。
  ➜ **推荐先用 UIO/自研**：你完全掌控 PL，读采样缓冲最直接。

## 2. 应用架构（Qt 或 LVGL 二选一）

```
┌───────────────────────────────┐
│  GUI (Qt Widgets / LVGL)       │
│   ├─ 波形绘制控件(折线/QPainter)│
│   ├─ 时基/幅度/触发/游标 控件   │
│   └─ 状态栏(采样率/电压)        │
├───────────────────────────────┤
│  数据层                         │
│   ├─ 打开采集设备(UIO/V4L2)     │
│   ├─ 定时/双缓冲读一批采样点    │
│   └─ 触发检测(上升沿/电平)      │
├───────────────────────────────┤
│  Linux 驱动/UIO + VDMA         │
└───────────────────────────────┘
```

- **Qt**：Linux 上最成熟，`QPainter` 画波形，控件全。正点原子教程里也有 Qt。
- **LVGL**：更轻，适合小资源/裸机风格，[已有人用它做示波器界面](http://openedv.com/thread-351300-1-36.html)。
  ➜ 若追求"跑起来快 + 界面现代"，**LVGL** 是不错选择；若追求"控件丰富 + 生态"，用 **Qt**。

## 3. 最小骨架（伪代码，C）

```c
// 1) 打开采集源
int fd = open("/dev/uio0", O_RDWR);          // 或 V4L2 open("/dev/video0")
void *buf = mmap(NULL, BUF_SIZE, PROT_READ|PROT_WRITE, MAP_SHARED, fd, 0);

// 2) 主循环
while (running) {
    wait_for_frame();                 // UIO irq / V4L2 DQBUF / 轮询采样就绪位
    uint8_t *samples = get_frame(buf);  // 一批 8-bit 采样
    int trig = find_trigger(samples, N); // 找触发点(可选)
    draw_waveform(samples + trig, N);    // 画到 Qt/LVGL 画布
    update_status(sample_rate, vpp);
}
```

**画波形要点**（性能）：把采样点按像素列抽稀（min/max 抽取），只画屏幕宽度的点，别逐点绘制。

## 4. 放进 PetaLinux 根文件系统

- Qt：`petalinux-config -c rootfs` → `meta-qt5` → 勾 `qtbase`，用 Yocto recipe 编你的 app。
- 或最简单：交叉编译成静态可执行，拷进 rootfs 的 `/usr/bin/`，开机脚本启动。
- 交叉编译器用 PetaLinux 自带的：
  `source .../settings.sh && $CROSS_COMPILE gcc ...`（`petalinux-build` 会给出 sysroot）。

## 5. 通过标准

- LCD 上显示实时波形，能改时基/幅度，触发电平可调。
- 到此，"**Zynq 上的嵌入式 Linux 智能示波器**"就成立了。
