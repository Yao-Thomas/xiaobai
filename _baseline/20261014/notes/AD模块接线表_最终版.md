## 四、★ 关键电气参数（来自官方手册）

```
3PA1030：
  · 最大 50 MSPS（输入时钟最高 50MHz）
  · 模拟输入 0V~2V → 数字 0~1023
★ 模块整体输入范围：-5V ~ +5V（板载衰减电路），换算 VO = VI/5 + 1
   VI=+5V → 数据 1023 ； VI=-5V → 数据 0 ； VI=0V → 数据约 512

★★★ OE 极性（关键）：
   【高电平 = 输出高阻态；低电平 = 正常输出】
   ⇒ 我们的 PL 必须把 OE 输出【低】

★ OTR（过量程标志）：模块有（JP1-14 / JP1-28），但我们的设计【没接】
   ⇒ 屏幕上显示的"输入过量程"是软件按 数据=1023 或 0 推断出来的

★ 采样时钟：我们的 PL 输出 20MHz（clk_wiz clk_out1），内部采样用 20MHz 270°
```

## 五、★ 接线顺序（建议）

```
第 1 步：先只接【GND】（J4-37 或 39 → JP1-2）
第 2 步：用万用表确认 J4-40 是 +5V
第 3 步：接【+5V】（J4-40 → JP1-1）
第 4 步：★ 先不接信号源，看示波器屏幕上的读数是否稳定（应约 512 附近，因为输入悬空≈0V）
第 5 步：接 24 根信号线（CH1 12 根 + CH2 12 根）
第 6 步：接信号发生器（SMA 转 BNC → 模块的两个 SMA 座）
         ★ 先给 1kHz 方波、幅值 ±1V（别超过 ±5V！）
第 7 步：用 cal_diag.py / cal_scope.py 做标定
```

## 六、★ 注意事项

```
① ★ 绝不能直接插 J4！信号定义完全不对，直插会短接
② ★ 信号发生器输出【不要超过 ±5V】，否则超量程
③ 杜邦线尽量短（20MHz 采样，长线会引入串扰）
④ 数据线不要接外部上拉/下拉（ADC 驱动它们）
⑤ OE 由 PL 输出，不用管
⑥ 接完先用 TESTPAT 内部波形对比一次（确认接线没接错位置）
```

## 七、验证方法（接完怎么确认接对了）

```
① 用内部测试波形 TESTPAT=1：屏幕应显示 CH1 三角波 + CH2 方波（9.756kHz）
② 关掉 TESTPAT，输入直流：
     · 输入 0V   → 数据应约 512（0.00V 附近）
     · 输入 +5V  → 数据应 1023
     · 输入 -5V  → 数据应 0
③ 输入 1kHz 正弦波（±1V）：屏幕应看到标准正弦波，频率显示 1.000kHz
④ 如果某个通道读数乱跳/恒定 → 大概率是那根线没接好（对应位的数据线）
```
