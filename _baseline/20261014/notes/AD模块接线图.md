## ★★ 接线原则（一句话）

```
ADC 模块接开发板的【J4】排针，用杜邦线按【JP1-n → J4-m】一一对应接
★ 绝不能直接插 J3（他的 26 个引脚和 7 寸 RGB LCD 的 24 个 RGB 脚完全重合）
```

## 三、★ 接线前必须确认（接错会烧！）

```
① ★★ 模块 JP1 的【电源和地】引脚定义 —— 我拿不到权威数据
     需要：模块丝印 / 说明书 / 原理图
     问用户：JP1 上哪几个是 5V / 3.3V / GND？
     ★ 这一条不清楚之前，不要上电接线

② 不要给 adc*_data 加外部上拉/下拉
     ADC 驱动这些线，FPGA 侧的弱保持器会和它打架
     （约束文件里已明确不设 PULLTYPE，靠默认 NONE）

③ OE 极性
     adc1_oe = W11 / adc2_oe = T9（FPGA 输出）
     3PA1030 的 OE：按手册确认高/低有效
     ⇒ 先不接信号，用万用表量电平

④ 采样时钟
     clk_wiz: clk_out1 = 20MHz 0°  → 前送给模块的 CLK
              clk_out2 = 20MHz 270° → FPGA 内部采样时钟
     实测 ADC_SETUP_SLACK = +5.629ns / HOLD_SLACK = +10.191ns ⇒ 余量充足 ✓
```
