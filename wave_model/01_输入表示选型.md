# 01 · 输入表示选型与两处"信息不可分"的实测结论

> 本文用**实测数据**回答两个问题：
> ① 接口 ② 建议的 STFT 到底够不够用？
> ② 任务书要求识别的四类异常，在 4096 点采集 + 28×28 画布上**是不是都可分**？

---

## 1. 背景：一条被忽略的硬约束

`07_接口约定单.md` 接口 ② 建议输入用**时频图（STFT）**，理由写得很好：
同样复用 2D CNN 加速器、信息保留优于栅格化折线图、对频率类故障更敏感。

但 STFT 有一条**硬约束**：要把谐波分开，一个窗内至少要装下 2 个周期。

```
窗内周期数 = K × NFFT / CAP_LEN
其中 K = 缓冲区内周期数，CAP_LEN = 4096
```

而**示波器为了"屏幕上显示 2~5 个周期"**（这正是 RL 自动设置的一项回报），
缓冲区内只有 `K = 2~5` 个周期：

| K | NFFT=512 窗内周期数 | 结果 |
|---|---|---|
| 2 | 0.25 | 谐波完全糊在一起 |
| 5 | 0.63 | 同上 |
| 16 | 2.0 | 勉强 |
| 64 | 8.0 | 良好 |

⇒ **少周期工况下，能用的 2D 表示只剩"时间×幅度"域。**

---

## 2. 第二种表示：时间×幅度密度图（wdens）

```
输入 : 4096 个 8 位样本
输出 : 28×28 uint8
  28 列 = 时间（4096 个点均分，每列 146 点）
  28 行 = 幅度（8 位码值均分；行 0 = 顶部 = 高电平）
  格值 = 该列内落在该幅度档的采样点【个数】
        → 除以该列总点数 = 列内密度
        → 开平方（方差稳定化，让弱轨迹也看得见）
        → 按本样本自身峰值归一化到 0~255
```

参考实现 `src/common/preprocess.py::capture_to_wdens_u8`（numpy / 纯 Python 双路径，已断言逐点一致）。

### 为什么密度图在两种工况下都有判别力

- **少周期（K=4）**：每列只覆盖 1/7 个周期，格点直接勾出波形形状
  ⇒ 正弦/方波/三角/锯齿肉眼可分。
- **多周期（K=64）**：每列覆盖 2.3 个周期，格值退化为**该列的幅度分布**，而：
  | 波形 | 幅度分布 |
  |---|---|
  | 正弦 | 反正弦分布（两端密、中间疏） |
  | 三角 | 均匀分布 |
  | 方波 | 双尖峰（两条轨） |
  | 噪声 | 高斯分布 |
  ⇒ 依然可分。而且**占空比异常直接表现为上下两条轨的亮度不对称**。

---

## 3. ★ 实测对比（同种子、同超参、同原始缓冲）

两个表示用**同一份随机种子**生成原始采集缓冲（`raw/*.npy` 逐字节相同），只换预处理。

### 实验一：9 类（含毛刺），gamma 扫描后取最优

| 表示 | test_acc | train_acc |
|---|---|---|
| wdens | 0.7960 | 0.7938 |
| **stft** | **0.8147** | 0.8178 |

### 实验二：8 类（去毛刺），固定 gamma=2.0 / calib_pct=99.9

| 表示 | test_acc | train_acc |
|---|---|---|
| **wdens** | **0.9265** | 0.9378 |
| stft | 0.9055 | 0.9276 |

### 结论（★ 我们的选择与理由）

**两轮实验互有胜负、差距都在 2% 量级**，所以不能只看准确率选：

1. **鲁棒性**：stft 在 `K<16` 时理论上就分不开谐波（§1），wdens 覆盖全 K 区间。
   交付的模型必须能吃示波器在**任何时基**下的采集。
2. **板端成本**：wdens 只需一次直方图；stft 要在 A9 上跑 28 次 512 点 FFT。
   （`preprocess.py` 两种都实现了，但密度图明显更省。）
3. **可解释性**：演示时把 28×28 密度图放大，观众**直接看到波形**；
   时频图需要解释才能看懂。

⇒ **交付采用 wdens**；stft 参考实现在 `preprocess.py` 里保留，随时可切换
（`dataset_gen.py --pp stft`）。**这个选择是有实测支撑的，不是拍脑袋。**

## 4. ★★ 关键发现：毛刺（glitch）在 28×28 画布上不可分

### 4.1 现象

9 类模型里，`glitch` 的召回率只有 **0.103**，而其他类都在 0.87~1.00。
模型几乎从不预测 glitch。

### 4.2 决定性实验一：二分类可分性

把任务压成【有毛刺 vs 干净波形（正弦/方波/三角/锯齿）】二分类，
用同一个 QWaveNet（`scripts/_diag_glitch.py`，train 11111 条，正例 20%）：

```
ep 10  train_acc 0.8000 | val 0.8002 test 0.7995 | 召回 clean 1.0000 glitch 0.0000
```

**`test_acc = 0.8000` 恰好等于正例比例 ⇒ 模型退化成"全判干净"。**
11k 训练样本、CNN、40 epoch，完全学不到毛刺。

### 4.3 决定性实验二：毛刺到底改了几个像素

同一份采集，复制一份注入毛刺（噪声完全一致），比较两张密度图
（`scripts/_diag_glitch2.py`）：

| K | 毛刺（宽6，+1.5×amp） | 密度图差异 |
|---|---|---|
| 6 | 饱和到 255（行 0） | **2 个像素**，最大 Δ=67 |
| 30 | 到 179 | **4 个像素**，最大 Δ=32 |
| 60 | 饱和到 255（行 0） | **5 个像素**，最大 Δ=122 |
| 30（小信号） | 到 158 | **3 个像素**，最大 Δ=38 |

全图非零格数：干净 658 → 带毛刺 658（**几乎不变**）。

### 4.4 为什么必然如此（信息论层面的原因）

```
一个毛刺只有 2~10 个采样点
一列 = 146 个采样点   ⇒ 毛刺只影响 1 列，占该列 1.4%~6.8%
该列要分摊到 28 个幅度档  ⇒ 毛刺只点亮 1~3 个格
⇒ 总信息量 = 2~5 个像素 / 784 个像素
```

而不同样本之间（K、相位、幅度、噪声、直流偏置全都随机）纹理本身的差异
**远大于**毛刺带来的 2~5 个像素的扰动。⇒ 不可分。

**这不是模型不够大、也不是训练不够久 —— 是 28×28 画布的表示能力上限。**

### 4.5 这与团队分工是自洽的

`06_分工总表_核对版.md` 里，示波器负责人的第 3 项任务原文：

> **3. PL 硬件级故障检测**
> ★ 为什么有价值：**毛刺是 ns 级的，CPU 采样根本采不到 —— 只有 FPGA 能在信号源头抓**
> 具体检什么：① 毛刺计数（脉冲宽度小于阈值）… 基于 100 MHz（10 ns 分辨率）

⇒ **毛刺本来就该由 PL 硬件检测器负责**（它看的是抽头之前的原始信号、10 ns 分辨率）；
AI 看到的只是**抽取后的 4096 点采集**，物理上已经丢掉了 ns 级信息。
这份实测数据正好**独立验证了团队的分工是对的**。

### 4.6 处置

- **交付 8 类**：`sine / square / triangle / sawtooth / noise / clipping / signal_loss / duty_abnormal`
  —— 即"在 4096 点采集里看得见"的类别。
- `glitch` 的生成器与代码路径**完整保留**：`dataset_gen.py --with-glitch` 即可回到 9 类，
  一行代码不用改。`dds_sim.CLASSES_REQUIRING_PL` 明确标注了它归 PL 负责。
- `model_spec.json` 的 `classes_note` 字段把这条结论带给板子侧，避免集成时困惑。

## 5. 另一类"数据不可分"：标签设计错误（已修）

调参过程中还抓出两个**纯属数据集设计错误**的问题，都会制造人为的精度上限：

| 问题 | 症状 | 修复 |
|---|---|---|
| **干净方波的占空比与异常档重叠** | 干净方波取 0.475~0.525，异常档取 0.40~0.47 ⇒ 边界样本标签互斥 | 干净方波收紧到 **0.49~0.51**；异常轻度档 **0.40~0.46 / 0.54~0.60**，重度档 0.12~0.36 / 0.64~0.88 |
| **占空比异常用了正弦/三角/锯齿底波形** | ① 正弦的 duty 参数**根本不起作用** ⇒ 生成的样本与干净正弦逐点相同，是**纯错标签**；② 三角 duty=0.15 看起来就是锯齿波 ⇒ 与 sawtooth 类直接冲突（实测 duty→sawtooth 误判 34/250） | 占空比异常**只允许方波底波形**（"占空比"本来就只是方波/脉冲的属性） |

修完这两条，测试集准确率从 **0.8105 → 0.9265 → 0.9590**。
剩下 4% 的误差集中在"干净方波 ↔ 轻度占空比偏差"这条**刻意保留的细微边界**上
（任务书要求"能检出人眼不易察觉的异常"），属于合理取舍。
