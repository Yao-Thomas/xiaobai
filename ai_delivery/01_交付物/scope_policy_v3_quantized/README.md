# scope_policy_mlp —— 策略网络量化交付包

> 项目：系统管家小白（Zynq-7020）· 生成者：AI 训练负责人（任务 E）
> 格式依据：`07_接口约定单.md` 接口 ① + `00_接口冻结单.md`（沿用 `(acc×MFQ)>>16` 方案）

## 1. 这是什么

一个**74 维 int8 输入 / 因子化离散动作**的小 MLP 策略网络，
与上一轮 PL 侧 `cnn_fc_q` **逐位同构**（`acc=Σx_q·w_q -> (acc×MFQ)>>16 -> sat[-128,127]`），
接上既有 IP 的 FC 通路即可推理。动作因子数 [16, 16, 5]。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `weights.bin` | int8 权重，11264 字节（布局见 §4） |
| `model_spec.json` | 模型结构 + requant + 内存布局 + 动作解码 |
| `reference_in.bin` | ★ 32 组测试输入，每组 74 字节 int8 |
| `reference_out.bin` | ★ 对应输出，每组 37 字节 int8（与硬件逐位一致） |
| `README.md` | 本文件 |

## 3. ★ 怎么验证（板子侧唯一可靠做法）

```
for k in 0 .. 31:
    把 reference_in.bin[k*74:(k+1)*74] 依次送入 FC 通路
    逐层写 MFQ_per_layer 寄存器，读回各头 logits
    与 reference_out.bin[k*37:(k+1)*37] 逐点比对 -> 应 100% 相同
```

## 4. DDR 内存布局（weights.bin）

| 偏移 | 层 | 形状 | 字节 |
|---|---|---|---|
| `0x0000` | fc0 | [64, 74] | 4736 |
| `0x1280` | fc1 | [64, 64] | 4096 |
| `0x2280` | head0 | [16, 64] | 1024 |
| `0x2680` | head1 | [16, 64] | 1024 |
| `0x2A80` | head2 | [5, 64] | 320 |

- 每层 128 字节对齐，层间/文件尾补齐到 64 的倍数（cache line 安全）
- 索引顺序：`w[oc*IN + i]`（行主序，与 HLS cnn_fc_q 一致）；无偏置
- 文件总大小：**11264 字节**

## 5. requant（沿用上一轮方案，硬件零改动）

```
out = sat((acc * MFQ) >> 16)     # 算术右移=floor，饱和到 [-128,127]
```
| 层 | MFQ |
|---|---|
| fc0 | 328 |
| fc1 | 311 |
| head0 | 34 |
| head1 | 62 |
| head2 | 53 |

`MFQ` 是 HLS 的 `s_axilite` 寄存器，**每层独立传入**；PS 按上表顺序写入即可。

## 6. 动作解码（argmax -> 真实设置）

对第 i 个头取 argmax 得到下标 a_i，再查 `model_spec.json` 的 `decode.factors[i].decode[a_i]`：

- 头0 触发电平：[0, 17, 34, 51, 68, 85, 102, 119, 136, 153, 170, 187, 204, 221, 238, 255]（LSB）
- 头1 时基 DEC：[1, 2, 3, 4, 6, 8, 11, 15, 21, 30, 43, 61, 86, 122, 173, 255]
- 头2 垂直增益：[0.5, 0.707, 1.0, 1.414, 2.0]

## 7. 输入量化

观测 obs∈[-1,1] 量化为 `i8 = round(clip(obs,-1,1)×127)`。
板端必须用**同一套 obs 计算**（见 `src/rl/scope_env.py::_obs` / `audio_eq_env.py::_obs`），
再按上式量化，才能与 reference_in.bin 对齐。
