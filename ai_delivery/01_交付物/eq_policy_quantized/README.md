# eq_policy_mlp —— 策略网络量化交付包

> 项目：系统管家小白（Zynq-7020）· 生成者：AI 训练负责人（任务 E）
> 格式依据：`07_接口约定单.md` 接口 ① + `00_接口冻结单.md`（沿用 `(acc×MFQ)>>16` 方案）

## 1. 这是什么

一个**16 维 int8 输入 / 因子化离散动作**的小 MLP 策略网络，
与上一轮 PL 侧 `cnn_fc_q` **逐位同构**（`acc=Σx_q·w_q -> (acc×MFQ)>>16 -> sat[-128,127]`），
接上既有 IP 的 FC 通路即可推理。动作因子数 [9, 9, 9, 9, 9, 9, 9, 9]。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `weights.bin` | int8 权重，10240 字节（布局见 §4） |
| `model_spec.json` | 模型结构 + requant + 内存布局 + 动作解码 |
| `reference_in.bin` | ★ 32 组测试输入，每组 16 字节 int8 |
| `reference_out.bin` | ★ 对应输出，每组 72 字节 int8（与硬件逐位一致） |
| `README.md` | 本文件 |

## 3. ★ 怎么验证（板子侧唯一可靠做法）

```
for k in 0 .. 31:
    把 reference_in.bin[k*16:(k+1)*16] 依次送入 FC 通路
    逐层写 MFQ_per_layer 寄存器，读回各头 logits
    与 reference_out.bin[k*72:(k+1)*72] 逐点比对 -> 应 100% 相同
```

## 5. requant（沿用上一轮方案，硬件零改动）

```
out = sat((acc * MFQ) >> 16)     # 算术右移=floor，饱和到 [-128,127]
```
| 层 | MFQ |
|---|---|
| fc0 | 343 |
| fc1 | 439 |
| head0 | 67 |
| head1 | 75 |
| head2 | 91 |
| head3 | 82 |
| head4 | 68 |
| head5 | 65 |
| head6 | 90 |
| head7 | 84 |

`MFQ` 是 HLS 的 `s_axilite` 寄存器，**每层独立传入**；PS 按上表顺序写入即可。

## 6. 动作解码（argmax -> 真实设置）

对第 i 个头取 argmax 得到下标 a_i，再查 `model_spec.json` 的 `decode.factors[i].decode[a_i]`：

- 8 个头 = 8 段 EQ 增益（dB），中心频率 [125, 250, 500, 1000, 2000, 4000, 8000, 16000] Hz
- 每头 9 档：[-12.0, -9.0, -6.0, -3.0, 0.0, 3.0, 6.0, 9.0, 12.0]（dB）

## 7. 输入量化

观测 obs∈[-1,1] 量化为 `i8 = round(clip(obs,-1,1)×127)`。
板端必须用**同一套 obs 计算**（见 `src/rl/scope_env.py::_obs` / `audio_eq_env.py::_obs`），
再按上式量化，才能与 reference_in.bin 对齐。
