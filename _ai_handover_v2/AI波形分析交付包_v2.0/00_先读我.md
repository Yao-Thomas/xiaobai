## 30 秒上手

```powershell
cd 03_源码
pip install -r requirements.txt
python -m wave_ai.serve --model ..\01_交付物\model_bundle.pt --anomaly ..\01_交付物\anomaly_stats.npz --port 8000
```

另开一个窗口：

```powershell
python -m wave_ai.client --url http://127.0.0.1:8000 --health
python -m wave_ai.client --url http://127.0.0.1:8000 --file ..\01_交付物\fixtures\test_wave_square_0.json
```

服务启动日志会打印 **`板端填: http://<本机IP>:8000`**，把这个地址填进板端配置即可。

## 三条必须知道的限制

1. **训练数据是仿真**（真实链路建模，不是板卡实测）⇒ 真实数据到了请跑 `python -m wave_ai.finetune --real <目录>`，一条命令微调。
2. **`dec` 必须传对** ⇒ K/频率/时间类指标全依赖它，填错掉约 10 个点。
3. **dec=10、1 kHz 只有 2 个周期** ⇒ 抖动/占空比稳定度返回 null（我们不编数字）。演示完整质量报告请把 dec 调到 20~40。
