# 波形质量评估算法（方向 2）

> 代码：`wave_ai/quality.py`（约 300 行）
> 单帧耗时：约 15~20 ms（CPU）
> 验收实测：**上升时间误差 ≤0.5 µs**（采样间隔 0.5 µs）；**SNR 与真值噪声相关系数 −0.989**

---

## 0. 一句话

**能从原始采样算的，绝不从图上估；算不出来的，一律返回 `null` 并说明原因。**

96×96 密度图里一列 = 42.7 个采样点；dec=10 时一列 = 21 µs。而典型上升时间是 1 µs 量级——
在图上只占 0.06 列，**根本看不见**。所以所有时间类指标都从 4096 点原始采样算。

---

## 1. 处理链

```
4096 点 (10 bit)
   │
   ├─① 稳健幅度/中值电平（0.5/99.5 分位，避开单点毛刺）
   │
   ├─② 周期估计：过零点间隔（去抖）→ P，精度 ≈0.01%
   │     · 先用谱峰给"预期周期"，再按 0.5P 的最小间隔对过零点去抖
   │       （少周期正弦过中点斜率只有 ~1 LSB/点，噪声会制造十几次假穿越，
   │        实测不去抖会把纯正弦 THD 算成 428%）
   │     · ≤0.3 个周期的工频漂移不穿零 ⇒ 自动退回谱峰周期
   │
   ├─③ 谐波拟合（Hann 加窗 + 逐谐波剥离）→ THD、各次谐波幅度
   │     · 普通联合最小二乘在"非整数周期"下基波会漏进 2~8 次谐波
   │       （实测纯正弦 THD 被算成 20%，方波 32%）
   │
   ├─④ 时域逐边沿测 10%~90% 上升/下降时间 + 过冲/下冲
   │     · 不折叠！折叠要把 4096 点分到 512~2048 个相位箱，
   │       每箱 1~2 点，边沿只有 1~3 点宽，箱内平均本身会把边沿展宽
   │
   ├─⑤ 谱噪声底估 SNR（Welch + 高于所有谐波的频段取中位数）
   │     · 不用"拟合残差"当噪声：方波的边沿残差会被误算成噪声，SNR 假性偏低
   │
   ├─⑥ 逐周期抖动 / 占空比稳定度（需要 ≥4 个周期）
   │
   └─⑦ 综合评分（按波形类型选权重，缺项自动归一化）
```

---

## 2. 每个指标怎么算、什么时候是 null

| 指标 | 算法 | 可测条件 | 典型精度 |
|---|---|---|---|
| `rise_us` / `fall_us` | 逐边沿：线性插值找 10% 与 90% 穿越点，取中位数 | 方波/脉冲/阶跃/振铃/毛刺类，且能定周期 | ±0.25 µs（dec=10） |
| `overshoot_pct` | 上升沿 90% 点之后、下降沿之前的最高点相对 95 分位平台 | 同上 | ±1% |
| `undershoot_pct` | 下降沿之后的最低点相对 5 分位平台 | 同上 | ±1% |
| `snr_db` | Welch PSD；噪声频段 = max(3·f0, 0.30·Nyquist) ~ 0.48·Nyquist 的中位 PSD × Nyquist | 幅度 ≥6 LSB | ±2 dB |
| `thd_pct` | Hann 加窗、基波→8 次逐次拟合并从残差中剥离，THD=√(ΣAₕ²)/A₁ | 能定 f0（谱峰 + R²>0.3） | 纯正弦 <3%；方波 ≈41%（理论 41.4%） |
| `jitter_ns` | 逐周期上升沿间隔的标准差（去抖后） | **≥4 个周期** | ±1 采样间隔 |
| `duty_stability_pct` | 逐周期占空比的标准差 | **≥3 个周期** | ±0.5% |
| `duty_pct` | **折叠后一个周期**内高于中值的比例 | 能定周期 | ±0.5%（整窗直接数在 K 非整数时有 +8% 偏差） |
| `shape_fidelity` | 与同类理想波形（同占空比）的最大循环互相关 R² | 方波/正弦/三角/锯齿 | — |
| `score` | 7 个子分加权（噪声/形状/失真/过冲/边沿/稳定/撞轨），缺项归一化 | 类别可评估 | 0~100 |

### 为什么 `score` 要"看类别"

方波的 THD 天生 41%（奇次谐波），用"THD 越低越好"评分会得出"标准方波质量 0 分"的荒谬结论。所以：

- 正弦/三角/锯齿：**失真项用 THD**（越低越好）；
- 方波/脉冲/阶跃/振铃：**失真项用波形保真度**（与同占空比理想方波的 R²）；
- 噪声/丢信号：**不评估质量**（`applicable=false`，`score=null`）。

### 评分权重

| 子项 | 权重 | 满分条件 |
|---|---|---|
| 噪声（SNR） | 0.25 | ≥40 dB |
| 形状保真度 | 0.20 | R²≥0.99 |
| 失真（THD） | 0.15 | ≤0（正弦类） |
| 边沿 | 0.13 | 边沿 <1% 周期 |
| 过冲 | 0.12 | 0% |
| 稳定性（抖动+占空比） | 0.15 | 抖动 <0.2% 周期且占空比 σ<0.5% |
| 撞轨 | 0.10 | <0.2% 采样贴轨 |

`coverage` = 可测子项权重和 / 全部权重和，UI 可据此显示"质量报告完整度"。

## 3. 验证证据

### 3.1 上升时间（对已知二阶巴特沃斯阶跃）

| 带宽（×Nyquist） | 真值（连续时间） | 实测 | 误差 |
|---|---|---|---|
| 0.30 | 1.140 µs | 1.306 µs | +0.166 |
| 0.50 | 0.685 µs | 0.903 µs | +0.218 |
| 0.80 | 0.430 µs | 0.676 µs | +0.246 |

误差恒在 **半个采样间隔**以内（dec=10 ⇒ 0.5 µs），且方向恒定（线性插值对 S 形边的系统性偏差）。
⇒ 对外报"上升时间 1.2 µs"时，真实不确定度约 ±0.25 µs，这个我们写进模型卡片。

### 3.2 SNR 单调性

同一方波，叠加 1/4/12/30 LSB 噪声，测得的 SNR 单调下降，相关系数 **−0.989**。

### 3.3 不可测项

- 2 个周期的 1 kHz 方波：`jitter_ns=null`、`duty_stability_pct=null`（`notes` 说明"周期数不足"）；
- 噪声/丢信号：`score=null`、`applicable=false`；
- 整帧干净正弦：`thd_pct` <3%，`rise_us=null`（正弦没有"边沿"这个概念）。

## 4. 给板端的建议

演示"杀手级对比"时，**质量模式请把 dec 调到 20~40**：

| dec | 窗口 | 1 kHz 的周期数 | 能测什么 |
|---|---|---|---|
| 10 | 2.048 ms | 2.0 | 上升/下降、过冲、SNR、THD、占空比 |
| 20 | 4.096 ms | 4.1 | ↑ 再加 **抖动、占空比稳定度** |
| 40 | 8.192 ms | 8.2 | 抖动统计更稳，但时间分辨率降到 2 µs |

推荐演示话术：
```
端侧：  "方波"
我们：  "方波，占空比49.9%，峰峰1.01伏，上升1.2微秒，抖动97纳秒，信噪比42分贝，质量87分。"
```
