# 模型卡片 · 多模态波形分析模型 v2.0

> 模型名：`wavefusion96_v2`（96×96×3 视觉 + 59 维特征 + 端侧概率 融合）
> 版本：2.0.0（2026-10-21）
> 交付物：`runs/v2_full/model_bundle.pt`（1.2 MB，含权重/标准化参数/温度/类别表）
> 运行环境：CPU（4 线程）即可，单帧视觉推理 **7.7 ms**；完整分析 p50 **37 ms**

---

## 1. 它是什么 / 不是什么

| | 说明 |
|---|---|
| ✅ 是 | 一个**三模态融合分类器**：96×96×3 时幅图 + 59 维手工特征 + 端侧 8 类概率 → 16 类波形 |
| ✅ 是 | 一个**可解释的测量前端**：质量评估（方向 2）与异常判据（方向 3）全部由 DSP 与规则给出，每个数字可溯源 |
| ❌ 不是 | 不是 Qwen2-VL 级别的视觉语言大模型。语言部分由受控生成层完成（模板 + 可选 LLM 润色），见 §7 |
| ❌ 不是 | 不追求"端到端一句话"的通用性；追求的是**在 Zynq 板卡的真实工况下判得准、说得清、跑得动** |

**为什么不做 VLM 微调（技术判断，非能力限制）**

1. 契约硬指标：视觉 ≤800 ms、总 ≤8 s、断网可用、单帧 4096 点。VLM 在 CPU 上单帧就是秒级。
2. 数据：真实板卡数据要等采集清单（`docs/数据采集清单.md`）回来才有；用仿真数据微调 VLM 只会把仿真偏差学进语言层。
3. 事实全部可算：类别、频率、峰峰值、上升时间、THD、SNR 都是**测量值**，语言层不需要"重新推理"，需要的是"说准、说短"。

⇒ 选择"强视觉小模型 + 强测量 + 受控语言层"，并预留 LLM 润色接口。
如果后续要上 VLM，本服务的接口（`/waveform/analyze`）不需要改，替换 `analyzer.py` 的后端即可。

## 2. 类别定义（16 类，顺序冻结）

| # | 英文 | 中文 | 判定要点 | 数据来源 |
|---|---|---|---|---|
| 1 | `sine` | 正弦波 | 连续平滑、上下对称 | sim_hw |
| 2 | `square` | 方波 | 高低两电平、占空比 48%~52% | sim_hw |
| 3 | `triangle` | 三角波 | 上升下降均匀、峰尖 | sim_hw |
| 4 | `sawtooth` | 锯齿波 | 单向缓变后陡降 | sim_hw |
| 5 | `noise` | 噪声 | 无周期、全频带能量 | sim_hw |
| 6 | `clipping` | 削顶 | 峰顶/谷底被限幅削平（**底波形不含方波**） | sim_hw |
| 7 | `signal_loss` | 丢信号 | 平线或幅度骤降段 | sim_hw |
| 8 | `duty_abnormal` | 占空比异常 | 方波高低占比失衡（≤0.46 或 ≥0.54） | sim_hw |
| 9 | `pulse` | 窄脉冲 | 孤立 1~3 个矩形脉冲，其余平直 | sim_hw |
| 10 | `step` | 阶跃 | 单次电平跳变，前后平直 | sim_hw |
| 11 | `am` | 调幅波 | 包络起伏 ≥1 个周期 | sim_hw |
| 12 | `fm` | 调频波 | 周期疏密交替 | sim_hw |
| 13 | `ringing` | 振铃 | 边沿后阻尼振荡（8~30 周期/窗口） | sim_hw |
| 14 | `double_freq` | 双频叠加 | 两个非谐波相关频率、可见拍频 | sim_hw |
| 15 | `hum` | 工频干扰 | ≤0.3 个周期的极低频漂移 | sim_hw |
| 16 | `glitch` | 毛刺 | 正常波形上叠加 2~12 点尖峰 | sim_hw |

前 8 类与端侧 PL CNN **完全同名同序**（契约硬性要求）。新增 8 类只追加。

**类别定义的三个"坑"（已修，写在这里避免后人重踩）**

1. `clipping` 的底波形不能含方波：把方波"削"到 0.8 倍只是幅度变小，与干净方波数据上不可分（实测 clipping→square 误判 7/50）。
2. `duty_abnormal` 的轻度档必须与 `square` 留出间隔：方波 0.48~0.52，异常类 ≤0.465 / ≥0.535；否则两类在 96×96 上直接重叠。
3. `hum` 的幅度不能太小（<0.18 倍）：否则与"带直流偏置的干净正弦"不可分。

## 3. 训练数据

| 项 | 内容 |
|---|---|
| 来源 | `sim_hw_10bit`：按 3PA1030 + 真实信号源建模的**真实链路仿真**（不是理想波形） |
| 采样口径 | 10 bit、0~1023、20 MSPS / dec、4096 点；dec ∈ {1,5,10,20} 加权 |
| 真实链路建模 | 前端 2 阶低通（0.45~0.90 Nyquist）、13 LSB 量级高斯噪声、ADC 失调 ±28 LSB、增益 ±8%、触发相位随机、缓慢漂移 |
| 周期数 K | 65% 落在 [1.5, 8]（真实演示工况 dec=10、f≈1 kHz ⇒ K≈2），其余到 32 |
| 规模 | train 8000（16 类均衡 500/类）、val 2500、test 2500 |
| 增强 | 特征加噪 σ=0.03；**25% 概率丢弃端侧概率**（填 1/8 均匀先验 + available=0） |
| 困难域（只测） | 噪声 16~32 LSB、带宽 0.30~0.55 Nyquist、增益 ±20%、偏置 ±45 LSB |

| 类别 | P | R | 类别 | P | R |
|---|---|---|---|---|---|
| sine | 0.93 | 0.955 | pulse | 0.994 | 1.000 |
| square | 0.832 | 0.917 | step | 0.98 | 1.000 |

| duty_abnormal | 0.952 | 0.885 | glitch | 0.911 | 0.979 |

**已知混淆（重要，联调时要心里有数）**

1. **square ↔ duty_abnormal**：轻度占空比偏差（0.42~0.465）在 96×96 上只差几个像素；`square` 的 P=0.832 主要来自这里。
   ⇒ 现场用板端的占空比硬件测量值兜底（误差 ≤0.3%，比看图准）。
2. **hum**：与"带缓慢漂移的正弦"仍有 8% 混淆；`half_drift` 特征在低 K 时有歧义。
3. **glitch**：dec=10 时 1~6 µs 的尖峰才能看见；更窄的归 PL 硬件检测器（这本来也是团队分工）。
4. **训练域外的"过干净 + 过陡"方波**：噪声 <7 LSB 且边沿带宽 >0.9 Nyquist 的方波可能被判成 `glitch`
   （实测 1.5 LSB 噪声 + 0.35~0.85 Nyq 带限的合成方波，置信度 0.76~0.95 判为 glitch）。
   原因是残差通道在"没有噪声雾"时只剩边沿亮条，与毛刺的视觉签名接近。
   真实板卡实测噪声约 13 LSB，落在训练域内；如果你们的信号源异常干净，采 50 条给我，微调一轮即可覆盖。

## 5. 输入表示（为什么是 96×96×3）

| 通道 | 内容 | 解决什么 |
|---|---|---|
| ch0 | 绝对幅度密度（行=ADC 0~1023，0 行=高电平） | 有没有撞轨/削顶、绝对幅度 |
| ch1 | 每帧自归一化幅度密度 | 小信号（vpp 60 LSB）也能看清形状 |
| ch2 | 局部残差 \|x−滑动均值\| 的列最大值 / vpp（减自适应噪声底） | 毛刺、窄脉冲、陡边沿 |

- 96 列 × 42.7 采样/列；K≈2 时一个周期 48 列，形状细节是 28×28 的 3.4 倍边长。
- **诚实说明**：42.7 采样/列 ⇒ 一列 = 21 µs（dec=10）。上升时间 1.2 µs 在图上只占 0.06 列，
  **所以上升时间必须从原始 4096 点算**（`quality.py`），不能从图估。
- 59 维特征包含：vpp/频率/K/占空比/边沿数、谱平坦度/谐波比/THD、残差/撞轨/平坦段、
  包络调制、低频能量、双频度、SNR、漂移量，以及端侧 16 维概率（含 available 标志）。

## 6. 训练方法

- 结构：4 个 stride-2 卷积块（24/48/96/128）+ GAP/GMP → 256；特征 MLP 59→128→128；concat→256→16。
- 损失：focal CE（γ=1）+ label smoothing 0.03；AdamW，OneCycle，max_lr 2.5e-3，16 epoch，batch 128。
- 可复现：`--seed 20261021`；训练 11 min（24 核 CPU，10 线程）。
- 温度标定在 val 上做（NLL 最小），用于让 confidence 与真实正确率对齐。

## 7. 语言层（不是"大模型"，是受控生成）

- 默认：**模板 + 优先级裁剪**。所有数字来自上游测量，零幻觉；≤70 字；纯文本；单位全中文（伏/赫兹/微秒/分贝）。
- 可选：配置 `WAVE_LLM_URL/MODEL/KEY` 后，用 OpenAI 兼容接口把这句话改写得更自然；
  改写后仍校验"≤70 字 / 无 Markdown / 数字不新增"，不通过就回退模板。
- 生成的文本示例：
  - `方波，高低两电平，998赫兹，峰峰1.01伏，占空比49.9%，质量良好87分，上升1.2微秒。`
  - `噪声，无明显周期，峰峰0.31伏，建议检查信号源与探头接地。`

## 8. 已知限制

1. **仿真训练**：真实板卡数据未到。域偏移（更差噪声/带宽/增益）下 83.3%（验收口径）/ 87.7%（训练报告口径），说明有鲁棒性但不能替代真实微调。
2. **dec 必须准确**：K/f0/时间类指标全依赖 `fs_eff`；dec 填错准确率掉约 10 个点。
3. **时间分辨率 = 1 个采样间隔**（dec=10 时 0.5 µs）；更快的边沿只能报"≤0.5 µs"。
4. **抖动/占空比稳定度需要 ≥4 个周期**；dec=10、1 kHz 时窗口只有 2 个周期 ⇒ 返回 null（不编数字）。
5. **THD 对少周期有偏**：用 Hann 加窗 + 逐谐波剥离把纯正弦压到 <3%，但 K<2 时仍不建议引用。
6. 未知异常对"两类混合"这种**接近已知类**的形态检出率只有 28%（4.5% 误报）；对结构性未知（三音、扫频）未单独评估。
7. 端侧 `image_u8`（28×28）输入不支持，必须传 `samples`。

## 9. 复现

```bash
# 生成数据（约 4 min）
python scripts/gen_data.py --out data/ds_train --hard data/ds_hard \
       --train 12000 --val 2500 --test 2500 --hard-n 2500 --ood 600
# 训练（约 11 min）
python -m wave_ai.train --data data/ds_train --hard data/ds_hard \
       --out runs/v2_full --epochs 16 --limit 8000
# 异常统计 + 验收
python scripts/build_anomaly.py --run runs/v2_full --data data/ds_train
python -m wave_ai.acceptance --model runs/v2_full/model_bundle.pt \
       --anomaly runs/v2_full/anomaly_stats.npz --n 300
```
