# 未知异常检测（方向 3）

> 代码：`wave_ai/anomaly.py`
> 验收实测：正常样本误报率 **4.5%**，未知混合形态检出率 **28%**
> （分布外距离单独看：AUC 0.86；1% 误报下检出 30%，5% 误报下检出 49%）

---

## 0. 先说清楚它能做什么、不能做什么

| | |
|---|---|
| ✅ 能 | 检出**该类别不应出现的特征**：撞轨、长平线、窄脉冲、双频、低频调制、基线漂移、宽带噪声底 |
| ✅ 能 | 给出"这段波形离已知 16 类有多远"（马氏距离）与"置信度有多低" |
| ✅ 能 | 用人话说出判据：`features=["双频叠加","轻度削顶"]`、`suggestion="可能为两个信号源叠加或通道串扰"` |
| ❌ 不能 | 把"两类已知波形的叠加"稳定判成未知——这类信号常常**真的**像某个已知类（方波+工频漂移 ≈ hum 类） |
| ❌ 不能 | 替代 PL 硬件毛刺检测器（ns 级毛刺在 dec=10 的采样里已经被抽掉了） |

---

## 1. 三个信号

```
score = 0.45 × 距离分 + 0.25 × 置信度不足分 + 0.30 × 规则命中分
```

### ① 马氏距离（分布外）

- 用训练集 8000 条样本的 **256 维倒数第二层嵌入**，按类拟合高斯（协方差收缩 0.15）。
- 距离 = 到最近类中心的 Mahalanobis 距离；阈值在 **val** 上取 p99（不能在 train 上取，
  否则阈值偏小、误报率高于 1%）。
- 实测：val 距离 p50=12.3 / p99=18.3；OOD 混合 p50=16.2 ⇒ 分离度 AUC 0.86。

### ② 置信度不足

`max_prob < 0.55` 时开始计分，<0.20 满分。对应"与已知 16 类均不匹配"。

### ③ 规则命中（主力，可解释）

| 规则 | 判据 | 人话 |
|---|---|---|
| `rail` | 贴 0/1023 轨的采样 >0.4% | 满量程饱和 |
| `flat` | 连续平坦段（≥8 点）占比 >35% | 信号中断/平坦段 |
| `spike` | 局部残差最大值 > **本类 p99** 且 >0.55 | 窄脉冲毛刺 |
| `two_tone` | 非谐波相关的第二谱峰 > **本类 p99** 且 >0.10 | 双频叠加 |
| `am` | 包络调制深度 > **本类 p99** 且 >0.30 | 低频幅度调制 |
| `drift` | 前后半窗均值差 > **本类 p99** 且 >0.18 | 基线缓慢漂移 |
| `noise_like` | 谱平坦度 > **本类 p99** 且 >0.40 | 宽带噪声底偏高 |
| `overshoot` | 过冲 >12% | 边沿过冲 |
| `shape` | 方波类保真度 <0.85 | 波形畸变 |

★★ **阈值必须按类标定**，这是本模块最关键的一条经验：
固定阈值 `max_res>0.55` 会把 **43% 的干净方波**报成"毛刺"——因为方波的边沿残差天生就接近 1.0 倍半峰峰值。
改成"超过该类训练集 p99"后，单特征误报率回到 ~1%，而真正没见过的形态会在多个特征上同时越界。

### 判定

```
is_anomaly = (未知规则命中 ≥2 条)
           or (出现 rail / flat 这类单项即致命的)
           or (马氏距离 > val p99)
```
已知类别自带的特征不算未知（削顶类的"撞轨"、毛刺类的"尖峰"、工频类的"漂移"等）。

## 2. 实测结果

| 指标 | 数值 | 说明 |
|---|---|---|
| 正常样本误报率 | **4.5%**（9/200） | 测试集全部 16 类，含 `clipping`/`glitch` 这些"本来就异常"的类别 |
| 未知混合检出率 | **28%**（56/200） | OOD = 12 组两类混合（方波+工频、正弦+毛刺、调幅+削顶……） |
| 距离 AUC | 0.86 | OOD vs 正常 |
| 距离阈值 1% 误报下检出 | 30% | val p99 = 18.3 |
| 距离阈值 5% 误报下检出 | 49% | val p95 = 16.3 |

**为什么检出率不高**：OOD 是"两类已知波形叠加"，而我们的 16 类里**本来就有** `double_freq`（双频）、`hum`（工频叠加）、`am`（调制）这些复合形态，所以很多混合信号落在已知类的流形上。
这其实是泛化能力的另一面，不宜单纯当成缺陷。

**真正能体现能力的是规则判据**：即使 `is_anomaly=false`，`features` 里仍会列出"双频叠加/轻度削顶"等观察，
文本层会说"注意双频叠加"。UI 可以据此做黄色提示，而不必等 `is_anomaly=true`。

---

## 3. 演示建议

1. **双频叠加**：信号源 1 kHz + 3.5 kHz 相加 → 规则命中 `two_tone`，`features=["双频叠加"]`，文本给出"可能为两个信号源叠加或通道串扰"。
2. **工频干扰**：1 kHz 方波上叠 50 Hz → 判为 `hum`（已知类），文本"基线缓慢漂移，建议检查电源纹波与地环路"。
3. **毛刺**：方波 + 2~12 点尖峰 → 判为 `glitch`（已知类），文本"叠加窄脉冲毛刺，建议检查探头接地与走线"。
4. **真正的未知**：方波 + 轻度削顶 + 工频漂移三合一 → 多规则同时命中 ⇒ `is_anomaly=true`，`features` 列出 2~3 条。

## 4. 后续可做的（不在本次范围）

- 用真实板卡数据重标定 `feat_q`（每类 p99）——现在是仿真分布；
- 对"结构性未知"（三音、扫频、突发调制）单独建一个评估集，现在的 OOD 只有两类混合；
- 若要提高混合形态的检出，可加一个"输入重构误差"分支（自编码器），代价是每帧多 5~10 ms。
